Prefix Dialer

発信するだけで、国内の携帯・固定電話への通話に事業者プレフィックスを自動で付けます。 Automatically adds your carrier prefix when you call Japanese mobile and landline numbers.

標準の電話アプリはそのまま使えます。緊急通報・特番は、設定に関わらず決して書き換えません。 Keep using your normal phone app. Emergency and service numbers are never rewritten, whatever the settings.

できることFeatures

  • 番号種別ごとのルールPer-type rules 携帯 / 固定 / IP電話（050）ごとにプレフィックスと先頭 0 の扱いを設定できます。 Set the prefix and the handling of the leading 0 separately for mobile, landline and VoIP (050) numbers.
  • 事業者プリセットCarrier presets G-Call / 楽天でんわ。公開資料で動作を確認できたものだけを収録しています。 G-Call and Rakuten Denwa — only carriers whose behaviour was verified from public sources.
  • 細かい ON/OFFFine-grained switches マスタースイッチ、回線（SIM）ごとの ON/OFF、ローミング中の自動停止。 Master switch, per-SIM-line on/off, and automatic pause while roaming.
  • 除外リストExclusion list この番号だけは書き換えない、を番号単位で指定できます。 Mark individual numbers that must never be rewritten.
  • 発信記録Call records 各発信で何をしたか、付けなかった場合はその理由まで残ります。端末内のみ、いつでも消去できます。 See what the app did on each call, including the reason when no prefix was added. On-device only, erasable at any time.
  • 設定の書き出し / 読み込みExport / import ルールや除外番号を JSON で保存・復元できます。 Save and restore your rules and exclusions as JSON.

安全性の設計Safety by design

このアプリは発信番号を書き換えます。誤判定のコストは非対称です — プレフィックスが付かないのは割引が効かないだけですが、付けてはいけない番号に付ければ緊急通報の失敗や課金事故になります。だから迷ったら必ず「付けない」側に倒します。 This app rewrites the number you dial, and the cost of a mistake is asymmetric: failing to add a prefix merely loses a discount, while adding one where it does not belong could break an emergency call or cause an unexpected charge. When in doubt, the app always declines to rewrite.

設定に関わらず書き換えない番号Never rewritten, whatever the settings

  • 緊急通報（110 / 118 / 119 / 112）Emergency numbers (110 / 118 / 119 / 112)
  • 3 桁以下のすべての番号（1XY の特番帯）Every number of three digits or fewer (the 1XY service range)
  • # / * を含む番号（#7119 #8000 #9110 などの相談ダイヤル）Any number containing # or * (consultation lines such as #7119, #8000, #9110)
  • 184 / 186 で始まる番号、DTMF ポーズを含む番号Numbers starting with 184 / 186, and numbers containing a DTMF pause
  • 国際番号・日本国外の番号International numbers and numbers outside Japan

これはユーザー設定より上位の層で動き、どんなルールを書いても貫通しないことをテストで固定しています。 This guard sits above user settings, and tests pin down that no rule set can get past it.

プライバシーPrivacy

このアプリは、いかなる情報も収集・送信しません。インターネット権限（android.permission.INTERNET）を持っていないからです。これは方針ではなく技術的な制約で、Android は宣言されていない権限の使用を許しません。配布している APK を検査すれば、誰でも確認できます: The app does not collect or transmit any information. It does not hold the internet permission (android.permission.INTERNET). This is a technical constraint rather than a promise: Android does not let an app use a permission it has not declared. Anyone can verify it by inspecting the distributed APK: 

aapt2 dump permissions app-release.apk

解析・クラッシュレポート・広告・トラッキングのいずれも組み込んでいません。設定と発信記録は端末内にのみ保存されます。 There is no analytics, no crash reporting, no advertising and no tracking. Settings and call records are stored only on your device.
